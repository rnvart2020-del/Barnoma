# Barnoma

Barnoma — локальное персональное рабочее пространство для задач, планирования и заметок.

## Возможности

- Главная панель со статистикой и фокусом на активных задачах.
- Задачи со сроками, приоритетами и категориями.
- Поиск и фильтрация задач по статусу и категории.
- Полный календарь по месяцам с отдельными заметками на выбранные даты и задачами по дням.
- Заметки с автоматическим сохранением.
- Локальная регистрация и вход нескольких пользователей на одном компьютере через раздел «Моё пространство»; у каждого профиля отдельные задачи, заметки и настройки.
- Светлая и тёмная темы.
- Экспорт и импорт резервной копии в JSON.
- Автообновление из GitHub с проверкой архива, резервной копией, безопасной заменой файлов после остановки старого процесса и автоматическим перезапуском.

## Требования Windows

- Windows 10 или Windows 11.
- Python 3.10 или новее.
- Современный браузер (Edge, Chrome или Firefox).
- Интернет для загрузки обновлений. Основные функции работают локально.

Сторонние Python-пакеты не требуются.

## Установка и запуск

1. Открой https://github.com/rnvart2020-del/Barnoma
2. Нажми **Code → Download ZIP**.
3. Распакуй архив, например в `C:\Barnoma`.
4. Установи Python 3.10+ с https://www.python.org/downloads/ и включи **Add Python to PATH**.
5. Открой папку Barnoma.
6. Запусти `run.py` двойным нажатием или выполни в PowerShell:

   ```powershell
   py run.py
   ```

7. Если браузер не открылся автоматически, перейди по адресу http://127.0.0.1:8000.

Остановка: в окне терминала нажми **Ctrl+C**.

## Как работает обновление через кнопку

1. Запусти Barnoma именно через `run.py` и открой локальный адрес http://127.0.0.1:8000.
2. Нажми **Обновления** в верхней части приложения.
3. Подтверди установку.
4. Программа проверит последнюю версию в GitHub, скачает архив и проверит наличие обязательных файлов.
5. Перед заменой файлов текущие `index.html`, `run.py` и `README.md` будут скопированы в папку `backups` с датой и временем.
6. Отдельный вспомогательный файл `.barnoma_update_helper.py` дождётся завершения старого сервера, заменит файлы и запустит обновлённую Barnoma. Страница дождётся запуска нового сервера и обновится сама.

Если обновлений нет, программа сообщит, что установлена последняя версия. При ошибке загрузки текущие файлы останутся на месте. Для обновления нужен доступ к GitHub и интернет.

**Важно для первого перехода на исправленный обновлятор:** если текущая кнопка обновления не работает, старый `run.py` не может надёжно заменить сам себя. Один раз скачай новый `run.py` по ссылке https://raw.githubusercontent.com/rnvart2020-del/Barnoma/main/run.py и замени им старый файл в папке Barnoma. После этого запускай `run.py` как обычно — последующие обновления, включая обновление самого `run.py`, будут устанавливаться автоматически. Новый обновлятор запускает отдельную копию помощника, чтобы Windows не мешала замене файла `run.py`.

## Данные и резервные копии

Задачи, настройки и заметки сохраняются в localStorage браузера на этом компьютере. Они не синхронизируются между устройствами и браузерами. В разделе **Моё пространство** можно создать локальный аккаунт или войти в существующий. У каждого профиля свой набор задач, заметок и настроек; пароль хранится в виде PBKDF2-хеша, а не открытым текстом. Это не облачная регистрация: аккаунты доступны только в том же браузере на этом компьютере. Очистка данных браузера может удалить локальные аккаунты и их данные, поэтому регулярно экспортируй резервные копии. Восстановить забытый пароль пока нельзя.

Чтобы сохранить данные:
1. Открой раздел **Настройки**.
2. Нажми **Экспортировать данные**.
3. Храни скачанный JSON-файл в надёжном месте.

Для восстановления выбери JSON-файл в блоке **Восстановление данных**. Импорт заменяет текущие данные содержимым резервной копии.

Автообновление делает отдельную резервную копию файлов программы в папке `backups`. Оно не удаляет задачи и заметки из браузера.

## Публикация на GitHub Pages

1. Открой **Settings → Pages** в репозитории.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку **main** и папку **/(root)**.
4. Нажми **Save** и дождись публикации.

GitHub Pages публикует только веб-интерфейс. Установка обновлений через кнопку работает в локальной версии, запущенной через `run.py`, потому что только локальный Python-процесс может заменять файлы на компьютере.

## Устранение неполадок

- **Команда py не найдена:** переустанови Python и включи Add Python to PATH; попробуй `python run.py`.
- **Порт 8000 занят:** закрой другую программу на этом порту или поменяй `port = 8000` в `run.py`.
- **Страница не открылась:** вручную открой http://127.0.0.1:8000.
- **Не удаётся обновить:** проверь интернет и доступность GitHub. Подробности последней ошибки сохраняются в `.barnoma_update_error.log`, этапы обновления — в `.barnoma_update.log` в папке программы. Если используешь старый `run.py`, один раз замени его файлом по ссылке выше.
