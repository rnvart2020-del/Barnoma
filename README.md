# Barnoma

Barnoma — локальное персональное рабочее пространство для задач, планирования и заметок.

## Возможности версии 0.2.0

- Главная панель с общей статистикой и фокусом на активных задачах.
- Задачи со сроками, приоритетами и категориями.
- Поиск и фильтрация задач по статусу и категории.
- Календарь задач, сгруппированных по датам.
- Заметки с автоматическим сохранением.
- Светлая и тёмная темы.
- Экспорт и импорт резервной копии в JSON.
- Проверка последнего коммита на GitHub.

## Требования Windows

- Windows 10 или Windows 11.
- Python 3.10 или новее.
- Современный браузер (Edge, Chrome или Firefox).
- Интернет нужен для проверки GitHub. Основные функции работают локально.

Сторонние Python-пакеты не требуются.

## Установка и запуск

1. Открой https://github.com/rnvart2020-del/Barnoma
2. Нажми **Code → Download ZIP**.
3. Распакуй архив, например в `C:\Barnoma`.
4. Установи Python 3.10+ с https://www.python.org/downloads/ и включи **Add Python to PATH**.
5. Открой папку Barnoma.
6. Запусти `run.py` двойным нажатием или выполни в PowerShell:

   ```powershell
   py run.py
   ```

7. Открой http://127.0.0.1:8000, если браузер не открылся автоматически.

Остановка: в окне терминала нажми **Ctrl+C**.

## Данные и резервные копии

Задачи, настройки и заметки сохраняются в localStorage браузера на этом компьютере. Данные не синхронизируются между устройствами и браузерами.

Чтобы сохранить копию:
1. Открой раздел **Настройки**.
2. Нажми **Экспортировать данные**.
3. Храни скачанный JSON-файл в надёжном месте.

Для восстановления выбери этот JSON в блоке **Восстановление данных**. Импорт заменяет текущие данные содержимым резервной копии.

## Обновление

В этой версии кнопка **Обновления** проверяет доступность GitHub и показывает сведения о последнем коммите, но не устанавливает файлы автоматически.

Для ручного обновления:
1. Сохрани резервную копию в разделе **Настройки**.
2. Останови приложение сочетанием Ctrl+C.
3. Скачай новый ZIP из GitHub и распакуй его поверх или в новую папку.
4. Запусти `py run.py` снова.

Автоматическая загрузка и установка обновлений требует отдельного механизма обновления локальных файлов и будет реализована отдельным этапом.

## Публикация статической страницы на GitHub Pages

1. Открой **Settings → Pages** в репозитории.
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Выбери ветку **main** и папку **/(root)**.
4. Нажми **Save** и дождись публикации.

GitHub Pages публикует веб-интерфейс. Локальный запуск через `run.py` выполняется отдельно на компьютере.

## Устранение неполадок

- **Команда py не найдена:** переустанови Python и включи Add Python to PATH; попробуй `python run.py`.
- **Порт 8000 занят:** закрой другую программу на этом порту или поменяй `port = 8000` в `run.py`.
- **Страница не открылась:** вручную открой http://127.0.0.1:8000.
- **Не работает проверка обновлений:** проверь интернет и доступность GitHub API.
