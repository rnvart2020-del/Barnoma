# Barnoma

Локальное рабочее пространство: задачи, заметки и простая проверка обновлений на GitHub.

## Возможности

- Добавление, выполнение и удаление задач.
- Подсчёт общего количества, выполненных и оставшихся задач.
- Быстрые заметки с автоматическим сохранением в браузере.
- Проверка последнего коммита в основной ветке GitHub.
- Запуск локального сайта одной командой через `run.py`.

> **Важно:** данные задач и заметок хранятся в localStorage браузера на этом компьютере. Они не синхронизируются между браузерами и устройствами. Кнопка проверки обновлений показывает последний коммит GitHub, но пока не устанавливает новую версию автоматически.

## Требования для Windows

- Windows 10 или Windows 11.
- Python 3.10 или новее (для запуска встроенного HTTP-сервера используется стандартная библиотека Python).
- Современный браузер: Chrome, Edge или Firefox.
- Подключение к интернету нужно только для проверки изменений на GitHub.

Сторонние Python-пакеты не требуются.

## Установка и запуск

1. Открой страницу репозитория: https://github.com/rnvart2020-del/Barnoma
2. Нажми **Code → Download ZIP**.
3. Распакуй архив в удобную папку, например `C:\Barnoma`.
4. Установи Python 3.10+ с сайта https://www.python.org/downloads/ . Во время установки отметь **Add Python to PATH**.
5. Открой папку Barnoma.
6. Дважды нажми `run.py` или запусти через терминал:

   ```powershell
   py run.py
   ```

7. Сайт откроется по адресу http://127.0.0.1:8000

Чтобы остановить приложение, вернись в окно терминала и нажми **Ctrl+C**.

## Обновление проекта

1. Скачай свежий ZIP через **Code → Download ZIP** на GitHub.
2. Закрой старый локальный сервер (Ctrl+C).
3. Сделай копию старой папки на случай, если в ней остались нужные файлы.
4. Распакуй новую версию в папку проекта.
5. Запусти `py run.py` снова.

Задачи и заметки сохраняются в данных браузера, поэтому обычное обновление файлов проекта не должно их удалять. Не очищай данные сайта браузера, если хочешь сохранить записи.

## Устранение неполадок

- **Команда py не найдена:** переустанови Python и включи Add Python to PATH; можно попробовать `python run.py`.
- **Порт 8000 занят:** закрой другую программу, использующую порт 8000, или измени значение `port = 8000` в `run.py`.
- **Страница не открылась автоматически:** вручную открой http://127.0.0.1:8000 после запуска.
- **Не проверяются обновления:** проверь интернет-соединение и доступность GitHub API.

## Публикация страницы через GitHub Pages

В репозитории открой **Settings → Pages**. В разделе **Build and deployment** выбери **Deploy from a branch**, затем ветку **main** и папку **/(root)**, нажми **Save**. После публикации GitHub покажет адрес сайта в этом же разделе.

GitHub Pages публикует статическую страницу. Функция локального запуска через `run.py` работает отдельно на компьютере.
